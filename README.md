# Z-Console

> **Open Console Platform**

O Z-Console é um projeto open source que tem como objetivo criar uma plataforma moderna de videogame baseada em hardware de PC, oferecendo uma experiência semelhante à de um console tradicional, porém totalmente aberta para desenvolvedores, fabricantes e entusiastas.

Ao invés de reinventar o hardware, o projeto utiliza componentes amplamente disponíveis no mercado (AMD Ryzen, SSD NVMe, memória DDR4/DDR5, USB, HDMI etc.), reduzindo custos e permitindo futuras atualizações.

O objetivo é criar um ecossistema completo composto por:

- 🎮 Console
- 🖥 Sistema Operacional
- 🛠 SDK Oficial
- 🕹 Launcher
- 🛒 Loja Digital
- ☁ Serviços Online
- 📀 Suporte a mídia óptica
- 🎴 Suporte a cartuchos
- 🧩 Emulação
- 🌎 Comunidade Open Source

---

## Filosofia

O Z-Console acredita que videogames deveriam ser:

- Abertos
- Atualizáveis
- Reparáveis
- Modificáveis
- Preserváveis
- Desenvolvidos pela comunidade

Nosso objetivo não é competir diretamente com PlayStation, Xbox ou Nintendo, mas oferecer uma plataforma aberta para criação, distribuição e preservação de jogos.

---

## Objetivos

- Sistema operacional baseado em Linux
- Interface exclusiva para TV
- Inicialização direta no Launcher
- SDK gratuito
- API unificada para jogos
- Suporte a Vulkan
- Compatibilidade com controles USB e Bluetooth
- Instalação de jogos por download
- Execução de jogos nativos
- Compatibilidade com Proton
- Emuladores integrados
- Atualizações OTA
- Cloud Save
- Mods
- Multiplayer Online
